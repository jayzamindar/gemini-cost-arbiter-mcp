This is dangerous silently: plans signed by one instance can't be verified by another; and if PLAN_SIGNING_SECRET missing in prod, ephemeral random secret silently used. Fail closed in prod: if not secret: if production raise RuntimeError; else maybe warn and use ephemeral with clear warning.
